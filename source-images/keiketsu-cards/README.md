# 経穴カード画像（keiketsu-cards）

ChatGPT などで生成した経穴ポケモン風カードの保存先。

## 実装状況

| No. | 状態 | アプリ参照 |
|-----|------|------------|
| 1〜99 | **実装済み（全枚）** | `lib/cardImages.ts` → このフォルダ |

### HP（2026-08調整）

- No.1→**80** / No.2→**90** / No.3→**100** / No.4→**110** / No.5→**120** / No.6→**130** / No.7→**80** / No.8→**90**
- 詳細は `docs/keiketsu-99-card-prompts.md` の HP早見表 と `lib/keiketsuCardMeta.ts`

新しいカードを追加したら `lib/cardImages.ts` の該当 import を
`@/source-images/keiketsu-cards/{N}.png` に切り替える。

## フォルダ構成

```
source-images/keiketsu-cards/
  ├── 1.png … 99.png          ← アプリ取込用（必須・こちらを使う）
  ├── _labeled/               ← 人間が見分けやすい別名コピー（任意）
  │     └── 001_ガードン_中府.png
  └── README.md
```

## 命名規則

| 用途 | パス | 例 |
|------|------|----|
| **本番・取込用** | `source-images/keiketsu-cards/{N}.png` | `9.png`（合谷） |
| 見分け用（任意） | `source-images/keiketsu-cards/_labeled/{NNN}_{モンスター名}_{経穴}.png` | `009_タニパンチ_合谷.png` |

- `{N}` は **1〜99 の数字（ゼロ埋めなし）**。既存の `source-images/Orenda_Card/` と同じ形式
- 生成サイズは **750×1050 px**、形式は **PNG**
- 完成後にガチャ／コレクションへ反映するときは、中身を `Orenda_Card/{N}.png` に差し替えるか、`lib/cardImages.ts` の import 先をこのフォルダに変更する
- `_labeled` は作業用。アプリからは参照しない
